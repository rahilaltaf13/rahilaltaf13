# Upper Limb Rehabilitation System — Project Synopsis

## Overview
Rehabilitation is a critical component in restoring mobility and functionality for individuals affected by physical impairments caused by injuries, strokes, or neurological disorders. This project focuses on developing a rehabilitation system for upper-limb movement to support arm functionality through controlled, repetitive motion.

## Objective
Design and develop a functional upper-limb rehabilitation device using Computer-Aided Design (CAD) and 3D printing. The system uses pneumatic actuators to provide smooth, controlled motion intended to mimic therapeutic exercises prescribed in upper-limb physiotherapy.

## Design Approach
- Digitally model the system structure using CAD.
- Fabricate components using 3D printing for customized prototyping.
- Use pneumatic actuation to generate guided, repetitive movement.
- Emphasize simplicity, reliability, mechanical precision, affordability, and ease of maintenance.

## System Concept
The device is intended to provide guided arm movement through pneumatic actuation. The synopsis describes a mechanically driven approach that avoids complex sensor networks, graphical interfaces, and feedback systems.

## Expected Outcome
A functional pneumatic-driven rehabilitation system for guided upper-limb movement. The synopsis identifies evaluation considerations including:
- Consistency of motion
- Ease of use
- Adaptability to different therapy needs

## Potential Application
The project aims to contribute to rehabilitation engineering through an affordable and simple mechanical solution that may support clinical or home-based rehabilitation programs.
